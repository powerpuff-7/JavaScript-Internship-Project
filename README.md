JavaScript Internship Project

A hands-on JavaScript project featuring practical assignments and a capstone project designed to strengthen core JavaScript concepts and practical web development skills.

📌 About the Project

This repository contains JavaScript assignments and a Product Inventory & Analytics Dashboard developed as part of my JavaScript internship curriculum. It demonstrates the application of JavaScript fundamentals through practical coding exercises and a project-based approach.

🎯 Objectives

- Understand core JavaScript concepts.
- Develop logical thinking and problem-solving skills.
- Practice writing clean and structured code.
- Apply JavaScript concepts to real-world scenarios.
- Build practical web development experience.

📚 Assignments Covered

The curriculum covers the following JavaScript concepts:

- Variables and Data Types
- User Input and Type Conversion
- Conditional Statements and Switch Cases
- Loops and Iteration
- Functions and Scope
- Arrays, Objects, and Their Methods

🚀 Capstone Project: Product Inventory & Analytics Dashboard

The capstone project demonstrates how JavaScript can be used to manage product information and perform basic inventory calculations.

Key Features

- Product and inventory management
- Product categorization
- Inventory calculations and summaries
- Tax and discount calculations
- Formatted reports and analytics
- Application of JavaScript fundamentals to practical problems

🛠️ Technologies Used

- HTML5 – Web page structure
- CSS3 – Styling and layout
- JavaScript (ES6+) – Logic, calculations, and interactivity
